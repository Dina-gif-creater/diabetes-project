# 🩺 Diabetes Prediction Web App

A Machine Learning based Diabetes Prediction Web Application developed using **Python**, **Scikit-Learn**, and **Streamlit**.
This application predicts the likelihood of diabetes based on user health input parameters through an interactive web interface.

---

# 🚀 Live Demo

🌐 Streamlit App:
https://diabetess-predictor.streamlit.app/

---

# 📌 Features

✅ User-friendly Streamlit interface
✅ Diabetes prediction using Machine Learning
✅ Interactive charts and visualization using Plotly
✅ Real-time prediction results
✅ Cloud deployment with Streamlit Community Cloud

# ⚙️ Installation and Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/diabetes-project.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd diabetes-project
```

## 3️⃣ Install Required Packages

```bash
pip install -r requirements.txt
```

## 4️⃣ Run Streamlit App

```bash
streamlit run app.py
```

# 🎯 Prediction Parameters

The model predicts diabetes risk based on inputs like:

* Glucose Level
* Blood Pressure
* BMI
* Insulin
* Age
* Pregnancies
* Skin Thickness
* Diabetes Pedigree Function
